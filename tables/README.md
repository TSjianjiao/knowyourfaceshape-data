# Dated comparison tables

Every table the site publishes, one pair of files per article (`.md` for reading, `.json` for machines). Exported 2026-09-19 from the article sources; the live pages are linked from each file.

Convention behind these tables: one row is one **published** position, ordered by publication date, each row carrying the date it was published, what kind of source published it, and the number or instruction it gave. Sources are named so each row can be checked; no links are given to them.
